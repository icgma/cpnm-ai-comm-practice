隐私政策

本站为纯静态课程门户。不设账号、不收作业、不采集姓名学号；仅用百度统计了解匿名访问情况。

托管：GitHub Pages 统计：百度统计 最后更新：2026-10-16

本站收集什么信息？

本站是纯静态页面，没有用户账号、没有评论、没有表单。不收集姓名、学号、邮箱。

部分页面加载 analytics.js。这个文件不读姓名或学号。它向页面插入百度统计脚本 https://hm.baidu.com/hm.js?959465d4f30700d97fc79ce460247967。百度统计记下匿名访问：打开了哪一页、从哪来、设备类型，并可能写入 Cookie。这些记录不和作业、成绩放在一起。

在浏览器里拦截 hm.baidu.com，这段统计就不会运行。

关于 Cookie

本站不设置登录 Cookie。访问统计由百度统计提供，可能使用 Cookie 或类似技术记录匿名访问（页面、来源、设备类型等），不用于识别个人身份、也不与学号或作业成绩关联。

如果您在浏览器中看到来自 github.io 域的 Cookie，那是 GitHub Pages 平台自身设置的，用于平台运维（详见 GitHub 隐私声明）。

第三方资源

本页面会从以下第三方域加载资源（这些域可能记录访问 IP 等基础日志）：

  • 百度统计（hm.baidu.com）— 由 analytics.js 插入，记录匿名访问
  • Google Fonts（fonts.googleapis.com）— 加载中文字体
  • jsDelivr CDN（cdn.jsdelivr.net）— 加载 Chart.js 图表库（仅趋势页）

百度统计的数据处理说明见 百度统计隐私政策。您可在浏览器中拦截第三方脚本以停用统计。
