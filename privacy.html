隐私政策

最后更新：2026-05-03

本站收集什么信息？

不收集任何个人信息。本站是托管在 GitHub Pages 上的纯静态页面，没有用户账号、没有评论系统、没有表单提交。

关于 Cookie

本站不主动设置任何 Cookie。如果您在浏览器中看到来自 github.io 域的 Cookie，那是 GitHub Pages 平台自身设置的，用于平台运维（详见 GitHub 隐私声明）。

第三方资源

本页面会从以下第三方域加载资源（这些域可能记录访问 IP 等基础日志）：

  • Google Fonts (fonts.googleapis.com) — 加载中文字体
  • jsDelivr CDN (cdn.jsdelivr.net) — 加载 Chart.js 图表库（仅趋势页）

本站作者无法访问、不会请求这些第三方的访问日志。

内容来源

每日趋势汇编基于公开 RSS 源自动抓取后由大语言模型重写。原始链接均指向源站，不复制原文长内容。

联系

问题请到 GitHub Issues 反馈。
