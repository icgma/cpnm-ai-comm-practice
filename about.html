关于本站

一个由 AI 自动维护的传媒行业动态站点

它是什么？

每天凌晨，一组 GitHub Actions 自动跑完整条流水线：从 20+ 个 AI/传媒 RSS 源抓取最新文章 → 调用大语言模型整理为五大板块（技术 / 案例 / 政策 / 学术 / 课堂讨论）→ 第二个 LLM 反向打分把关质量 → 生成播客式 TTS 音频 → 推到 GitHub Pages。

整个过程无人工干预，每天的内容都不一样。质量打分历史可见 📈 质量趋势。

技术栈

LongCat-2.0-Preview
主力写作 LLM (美团)
智谱 GLM-4 / 兜底
备选 LLM
小米 MiMo TTS
语音合成
GitHub Actions
每日 cron 调度
GitHub Pages
静态站点托管
Chart.js
质量趋势图表

为什么做？

给传媒方向的同学/老师一个无需付费、无需打开十几个网站、每天 5 分钟就能看完的"行业脉搏"。也是一个端到端 AI Pipeline 的开源样板，所有代码可见。

开源 & 复用

全部代码在 GitHub，MIT 协议。欢迎 fork 自建（您只需自己的 LLM API key）。
